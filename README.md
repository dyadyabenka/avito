# Сниппер ноутбуков с полуавтоматическим предложением цены

Бот ловит новые объявления, разбирает характеристики, считает цену закупки
и присылает карточку с кнопками. Отправляет сообщение продавцу человек.

## Запуск за 10 минут

```bash
pip install -r requirements.txt
cp .env.example .env      # заполнить TELEGRAM_TOKEN и OWNER_ID
set -a && source .env && set +a
python main.py
```

При `USE_MOCK=1` бот работает на `mock_listings.json` — можно проверить
весь конвейер, не трогая площадку. Отправьте боту `/start`, и через
пару минут придут карточки по тестовым объявлениям.

## Команды

- `/market 1050 1060 1070` — срез рынка по видеокартам: медиана, коридор
  цен, разброс, скорость ухода. Без аргументов покажет, какие карты уже
  есть в базе.
- `/stats` — что накопилось.

## Что делают кнопки

- **Взять** — присылает готовый текст для продавца и ссылку. Копируете,
  открываете объявление, вставляете в чат.
- **Своя цена** — пришлите число, бот пересчитает текст под неё.
- **Мимо** — помечает лот, больше не показывает.

## Как считается цена

```
медиана по модели  →  потолок = медиана × (1 − маржа) − резерв на подготовку
предложение        =  min(потолок, цена_объявления × 0.9), округлённое до 500
```

Пока по модели меньше 4 объявлений, медианы нет — бот считает от цены
объявления и ставит вердикт «проверить лично». База наполняется сама,
через 2–3 недели оценка становится осмысленной.

Объявления с метками «не включается», «на запчасти», «следы залития»,
«менялась видеокарта» не оцениваются вообще — только вердикт
«проверить лично».

## Что здесь честно недоделано

1. **Медиана считается по ценам предложения, а не по сделкам.** Это
   систематически завышает оценку: часть лотов висит месяцами и не
   продаётся. Правильнее — брать цены объявлений, которые исчезли из
   выдачи за 3–14 дней. Поле `last_seen` для этого уже пишется, логику
   надо дописать, когда накопится история.
2. **`HttpSource` — самое хрупкое место.** Разметка меняется, вместо
   выдачи может прийти проверка. Класс намеренно изолирован: меняйте
   способ получения данных, не трогая остальной код. Никаких обходов
   защиты в нём нет и добавлять их не нужно — если площадка не отдаёт
   данные, честнее сменить источник, чем воевать с ней с рабочего
   аккаунта.
3. **Дедупликация моделей грубая.** Ключ строится из бренда, процессора,
   ОЗУ и накопителя. Одна и та же модель с разным описанием иногда
   попадёт в разные корзины. Лечится, когда станет видно на реальных
   данных, какие именно совпадения теряются.
4. **Нет фото в карточке.** Для ноутбуков фото решает половину вопроса о
   состоянии. Добавить `photo_url` в источник и слать
   `answer_photo` — следующий очевидный шаг.

## Настройка под нишу

Основной рычаг — `TARGET_MARGIN`. При 0.25 бот отсечёт почти всё, что
продаётся по рынку: перекуп зарабатывает на закупке ниже медианы. Если
карточек приходит слишком мало, снижайте до 0.15–0.18 и смотрите, что
из этого реально доходит до сделки.

`MAX_PRICE` держите чуть выше верхней границы ниши, иначе в базу не
попадут дорогие лоты и медиана по флагманским моделям не наберётся.
